# OpenInNewTab 2.1.2

## 新功能

- 在设置页主动获取云端社区规则，浏览、预览并选择需要导入的规则
- 支持自定义规则来源，或恢复默认 GitHub 来源
- 访问已有规则但当前设备尚未授权的网站时显示浏览器通知
- 通知提供「前往设置」和「关闭」两个操作，通知正文也可进入设置
- 设置页可以集中授权所有启用规则缺少的网站权限
- 每条规则分别显示「授权网站」或「已授权」，支持单独授权
- 在目标网站打开扩展弹窗时，只在缺少权限的情况下显示当前网站授权入口
- 完成当前网站授权后立即加载规则，无需重新导入或保存

## 修正

- 更新 PSNINE 社区规则，排除分页链接
- 更换规则来源或删除规则时，只撤销不再使用的网站权限

## 同步行为

- 规则、启用状态和规则来源地址通过 Chrome 同步
- 网站访问权限由 Chrome 保存在当前设备，需要用户在每台设备上确认
- 缺少本机权限不会停用同步规则，也不会影响其他设备
- 浏览器通知按网站在当前会话中去重，刷新页面不会重复提醒

## 权限和隐私

- 新增 `webNavigation`，仅在本机将顶层页面地址与用户已有规则比较
- 新增 `notifications`，仅在命中规则但当前设备缺少权限时显示提醒
- 页面地址不会因此写入同步存储，也不会发送给开发者或第三方
- 网站权限仍按需申请，安装时无需授予全部网站访问权限
- 云端规则仅为结构化 JSON 数据，不加载或执行远程代码
