本版处理规则同步到其他设备后、本机缺少网站权限的情况：给出一次提醒，并引导用户完成授权。

## 主要更新

- **授权提醒**：访问已有规则但本机尚未授权的网站时显示一次浏览器通知，同一浏览器会话按网站去重。
- **集中授权**：点击通知进入设置页，可以集中授权所有启用规则缺少的网站权限。
- **逐条授权**：每条规则分别显示「授权网站」或「已授权」，支持单独申请。
- **Popup 入口**：在目标网站打开扩展弹窗时，只在缺少权限的情况下显示当前网站授权入口。
- **即时生效**：完成当前网站授权后立即加载规则，无需重新导入或保存。

新增 `webNavigation` 和 `notifications` 权限。页面地址只在本机与已有规则比较，不写入同步存储，也不发送给开发者或第三方；缺少本机权限不会停用同步规则，也不影响其他设备。
