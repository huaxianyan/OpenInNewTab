本版把「导出规则」从一键下载改成可勾选的导出窗口，并新增面向社区规则贡献的导出方式，方便把整理好的规则直接提交到规则仓库。

## 主要更新

- **导出前可勾选**：点击「导出规则」先打开选择窗口，逐条勾选需要导出的规则，不再只能整体导出。
- **导入用导出**：选中的规则合并成一个 JSON 文件，可以再次导入扩展，用于备份或迁移。
- **社区规则用导出**：按网站拆成多个规则文件并打包为 ZIP，解压后的文件可直接提交到 `rule-sets/`。
- **导出结果预览**：选择窗口内实时显示将要生成的文件名和数量，勾选变化即时更新。
- **社区规则上游自动维护**：规则仓库的索引改由自动流程生成，贡献者只需提交单个规则文件。

本次只调整导出交互，规则格式、网站权限和同步行为与 2.1.2 相同，可以直接覆盖安装。

完整验收清单见 [发布验收](https://github.com/huaxianyan/OpenInNewTab/blob/v2.2.0/docs/release-checklist.md)。
