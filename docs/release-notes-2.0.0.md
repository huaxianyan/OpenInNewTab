这是原 Chrome 扩展从 Manifest V2 迁移到 Manifest V3 后的首个正式版本，安装时不再申请访问所有网站。

## 主要更新

- **按网站规则**：按网站创建和管理新标签打开规则，在页面中可视化选择同类链接并即时预览范围。
- **排除项**：可以添加多条排除项，逐条预览和删除，并能可视化编辑已有规则。
- **两种打开方式**：提供兼容模式和保护模式，用于网站接管普通点击的情况。
- **当前网站管理**：在扩展图标中启停、编辑或删除当前网站的规则。
- **规则集导入导出**：导入、预览、按项选择和导出规则集，内置 V2EX、NGA 和 PSNINE 规则。
- **按需申请权限**：只在创建或导入规则时申请对应网站权限，删除网站最后一条规则后撤销。

保留真实链接地址和浏览器原生导航，支持中键、右键菜单和组合键操作，以及动态生成的链接和单页应用页面。扩展不包含广告、统计或行为追踪，不加载或执行远程代码。

完整验收清单见 [发布验收](https://github.com/huaxianyan/OpenInNewTab/blob/v2.0.0/docs/release-checklist.md)。
