# OpenInNewTab 2.0.0

这是原 Chrome 扩展从 Manifest V2 迁移到 Manifest V3 后的首个正式版本。

## 新功能

- 按网站创建和管理新标签打开规则
- 在页面中可视化选择同类链接
- 扩大或缩小选择范围并即时预览
- 添加多条排除项，逐条预览和删除
- 可视化编辑已有规则
- 提供兼容模式和保护模式
- 在扩展图标中管理当前网站规则
- 导入、预览、按项选择和导出规则集
- 提供 V2EX、NGA 和 PSNINE 可选规则集

## 权限和隐私

- 安装时不再访问所有网站
- 只在用户创建或导入规则时申请对应网站权限
- 删除网站最后一条规则后撤销对应权限
- 不包含广告、统计和行为追踪
- 不向开发者服务器发送浏览记录
- 不加载或执行远程代码

## 兼容性

- 保留真实链接地址和浏览器原生导航
- 支持中键、右键菜单和组合键操作
- 支持动态生成的链接和单页应用页面
