# Chrome Web Store 发布验收

每个正式版本都应从 `dist` 中的 ZIP 开始验收，不直接加载源码目录。使用：

```powershell
pwsh -File .\scripts\test-clean-package.ps1
pwsh -File .\scripts\start-clean-test.ps1 -Reset
```

## 自动验收

- [ ] ZIP 根目录包含 Manifest V3
- [ ] service worker 能启动并读取正确版本
- [ ] Popup 能完整加载
- [ ] 设置页能完整加载
- [ ] 发布包文件与源码哈希一致

## 首次安装与权限

- [ ] 安装时不要求访问所有网站
- [ ] 未授权网站不会运行规则
- [ ] 首次点击「选择页面上的链接」只申请当前网站
- [ ] 允许权限后直接进入可视化选择
- [ ] 拒绝权限后可以重新操作
- [ ] 首次授权后取消选择会撤销未使用的网站权限

## 规则生命周期

- [ ] 新建规则后当前页面立即生效
- [ ] 刷新页面后规则继续生效
- [ ] Popup 能启停当前网站规则
- [ ] Popup 能切换兼容模式和保护模式
- [ ] 可视化编辑能恢复主范围、模式和排除项
- [ ] 点击单条排除项只突出它负责的链接
- [ ] 可以单独删除任意排除项
- [ ] 删除网站最后一条规则会撤销网站权限

## 浏览器原生操作

- [ ] 普通左键只打开一个新标签
- [ ] 中键不会重复打开
- [ ] 右键菜单显示真实链接地址
- [ ] `Ctrl` 或 `Command` 点击保持浏览器原有行为
- [ ] `Shift` 点击保持浏览器原有行为
- [ ] 下载链接不被规则接管
- [ ] `mailto:`、`tel:` 和 `javascript:` 不被规则接管

## 网站场景

- [ ] V2EX 主题链接使用兼容模式
- [ ] NGA 链接使用保护模式，原标签不跳转
- [ ] PSNINE 排除页头和标签云
- [ ] 动态加载的新链接无需重新配置
- [ ] GitHub 等单页应用中的兼容模式不破坏站内导航

## 导入和导出

- [ ] 能导出当前全部规则
- [ ] `rule-sets/v2ex.json` 可以预览并导入
- [ ] `rule-sets/nga.json` 可以预览并导入
- [ ] `rule-sets/psnine.json` 可以预览并导入
- [ ] 可以取消勾选部分规则
- [ ] 重复规则显示「将更新」且不会重复创建
- [ ] 无效 JSON 和不支持的版本会显示可操作的错误

## Chrome 最终验收

自动测试允许使用 Microsoft Edge，但提交 Chrome Web Store 前必须再使用当前稳定版 Google Chrome 完成：

- [ ] 从正式 ZIP 解压并加载
- [ ] 完成一次首次授权和拒绝授权
- [ ] 完成一次规则创建、编辑和删除
- [ ] 确认扩展详情页没有错误
- [ ] 确认版本号与准备上传的 ZIP 一致
