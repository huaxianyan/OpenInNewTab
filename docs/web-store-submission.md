## 简短说明

按网站设置规则，让指定链接在新标签中打开。支持页面内可视化选择、排除链接和保护网站原有导航。

## 详细说明

有些网站会让普通左键点击始终在当前页面打开，或者通过脚本接管链接行为。新标签打开规则允许你按网站选择需要处理的链接，并保留其他链接原有的打开方式。

主要功能：

- 在页面上直接选择同类链接，无需手写规则
- 扩大或缩小匹配范围，并即时预览结果
- 添加多条排除项，单独查看每条排除项负责的链接
- 在兼容模式和保护模式之间切换
- 从扩展图标快速启停、编辑或删除当前网站规则
- 导入、预览、按项选择和导出规则
- 支持动态生成的链接和单页应用页面

扩展安装时不会要求访问全部网站。只有你为某个网站创建或导入规则时，浏览器才会请求该网站的访问权限。

兼容模式保留网站原有点击处理。保护模式用于网站接管普通点击的情况，它会阻止网站处理该次点击，再由浏览器执行链接原生导航。真实链接地址始终保留，因此中键、右键菜单和复制链接仍可正常使用。

扩展不包含广告、统计或行为追踪，不向开发者服务器发送浏览记录，也不加载远程代码。

## 单一用途

允许用户按自己配置的网站和链接规则，在新标签中打开指定链接。

## 权限说明

### `activeTab`

用户点击扩展图标后，临时访问当前标签页，用于识别当前网站并启动页面内可视化链接选择。扩展不会依靠此权限在用户未操作时访问其他标签页。

### `scripting`

在用户已经授权的网站中注入链接规则处理脚本和可视化选择界面。脚本只用于匹配、预览和处理用户配置的链接。

### `storage`

使用 Chrome 扩展存储保存和同步用户创建的规则，包括网站范围、链接范围、排除范围、打开方式和启用状态。开发者无法访问用户的 Chrome 同步存储。

### 可选网站权限 `*://*/*`

这是可选权限声明，不在安装时授予。扩展适用于用户自行选择的网站，因此需要允许用户在运行时申请任意 HTTP 或 HTTPS 网站。实际使用时只请求用户当前创建或导入规则所涉及的网站；删除该网站最后一条规则后会撤销对应权限。

## 数据使用披露

建议在「收集的用户数据」中选择不收集用户数据。扩展会在本地读取当前页面 URL 和链接元素以执行用户规则，但不会把网站内容、浏览记录或规则发送给开发者或第三方服务器。

规则通过 `chrome.storage.sync` 由 Chrome 管理。开发者没有服务器，也不能读取用户的同步数据。

需要确认以下声明：

- 不向第三方出售用户数据
- 不将用户数据用于与扩展单一用途无关的目的
- 不将用户数据用于信用评估或借贷
- 不使用或转移用户数据投放个性化广告
- 不包含分析、广告或追踪 SDK

## 远程代码声明

扩展不执行远程代码。所有 JavaScript 和 CSS 均包含在上传的扩展包中。仓库中的可选规则是结构化 JSON 数据，扩展不会联网自动下载，也不会把规则作为代码执行。

## 审核员说明

这是原有 Manifest V2 扩展的 Manifest V3 升级版本。

验证步骤：

1. 安装扩展，确认安装时不请求访问全部网站
2. 打开 `https://www.v2ex.com/`
3. 点击扩展图标，选择「选择页面上的链接」
4. 允许访问 `www.v2ex.com`
5. 点击一个主题链接，确认相似主题链接显示蓝色预览
6. 保存规则，普通点击主题链接后应在新标签中打开
7. 再次点击扩展图标，可以启停、切换模式、可视化编辑或删除规则
8. 删除该网站最后一条规则后，对应网站权限会被撤销

扩展不需要账号，不访问开发者服务器。
