## 简短说明

按网站设置规则，让指定链接在新标签中打开。支持页面内可视化选择、排除链接和保护网站原有导航。

## 详细说明

有些网站会让普通左键点击始终在当前页面打开，或者通过脚本接管链接行为。新标签打开规则允许你按网站选择需要处理的链接，并保留其他链接原有的打开方式。

主要功能：

- 在页面上直接选择同类链接，无需手写规则
- 扩大或缩小匹配范围，并即时预览结果
- 添加多条排除项，单独查看每条排除项负责的链接
- 在兼容模式和保护模式之间切换
- 从扩展图标快速启停、编辑或删除当前网站规则
- 导入、预览、按项选择和导出规则
- 主动获取云端社区规则，在弹窗中浏览并选择导入
- 自定义规则来源，或恢复默认来源
- 支持动态生成的链接和单页应用页面

扩展安装时无需授予全部网站的访问权限。为网站创建或导入规则时，浏览器会请求对应网站的访问权限。主动获取云端规则时，还会请求规则来源网站的访问权限。

兼容模式保留网站原有点击处理。保护模式用于网站接管普通点击的情况，它会阻止网站处理该次点击，再由浏览器执行链接原生导航。真实链接地址始终保留，因此中键、右键菜单和复制链接仍可正常使用。

扩展不包含广告、统计或行为追踪，不向开发者服务器发送浏览记录，也不加载远程代码。

## 单一用途

允许用户按自己配置的网站和链接规则，在新标签中打开指定链接。

## 权限说明

### `activeTab`

用户点击扩展图标后，临时访问当前标签页，用于识别当前网站并启动页面内可视化链接选择。扩展不会依靠此权限在用户未操作时访问其他标签页。

### `scripting`

在用户已经授权的网站中注入链接规则处理脚本和可视化选择界面。脚本只用于匹配、预览和处理用户配置的链接。

### `storage`

使用 Chrome 扩展存储保存和同步用户创建的规则，包括网站范围、链接范围、排除范围、打开方式和启用状态，以及用户选择的规则来源地址。开发者无法访问用户的 Chrome 同步存储。

### 可选网站权限 `*://*/*`

这是可选权限声明，不在安装时授予。扩展适用于用户自行选择的网站，因此需要允许用户在运行时申请任意 HTTP 或 HTTPS 网站。实际使用时请求用户当前创建或导入规则所涉及的网站，以及用户主动获取云端规则所需的来源网站。删除网站最后一条规则后，若该权限也未被当前规则来源使用，会撤销对应权限。更换规则来源后，也会清理不再使用的旧来源权限。

## 数据使用披露

建议在「收集的用户数据」中选择不收集用户数据。扩展会在本地读取当前页面 URL 和链接元素以执行用户规则，但不会把网站内容、浏览记录或规则发送给开发者或第三方服务器。

规则和规则来源地址通过 `chrome.storage.sync` 由 Chrome 管理。开发者没有服务器，也不能读取用户的同步数据。

用户主动获取云端规则时，扩展访问所选来源的索引及同站点规则文件。默认来源托管于 GitHub。请求不携带网站 Cookie，也不发送用户已有规则或浏览记录。来源服务提供者会接收到 IP 地址和请求时间等普通连接信息。请按此实际行为核对后台数据使用披露，并保留新版隐私政策中的网络访问说明。

需要确认以下声明：

- 不向第三方出售用户数据
- 不将用户数据用于与扩展单一用途无关的目的
- 不将用户数据用于信用评估或借贷
- 不使用或转移用户数据投放个性化广告
- 不包含分析、广告或追踪 SDK

## 远程代码声明

扩展不执行远程代码。所有 JavaScript 和 CSS 均包含在上传的扩展包中。云端规则是结构化 JSON 数据，仅描述网站范围、链接选择器、排除项和预定义打开模式。扩展仅在用户主动获取时联网读取，不会后台轮询或自动启用，也不会把规则作为代码执行。

## 审核员说明

2.0.0 已通过审核，本次 2.1.0 新增云端规则浏览和自定义规则来源，修正 PSNINE 分页链接的排除范围。Manifest 权限声明与 2.0.0 相同。

验证步骤：

1. 安装扩展，确认安装时不请求访问全部网站
2. 打开 `https://www.v2ex.com/`
3. 点击扩展图标，选择「选择页面上的链接」
4. 允许访问 `www.v2ex.com`
5. 点击一个主题链接，确认相似主题链接显示蓝色预览
6. 保存规则，普通点击主题链接后应在新标签中打开
7. 再次点击扩展图标，可以启停、切换模式、可视化编辑或删除规则
8. 删除该网站最后一条规则后，对应网站权限会被撤销

云端规则验证步骤：

1. 点击扩展图标，再点击「管理全部规则」进入设置页
2. 使用默认规则来源，点击「获取云端规则」并允许访问来源网站
3. 在云端规则弹窗中选择一个规则集，点击「查看并选择」
4. 预览并勾选需要的规则，确认导入并允许访问目标网站
5. 导入后返回云端规则列表，可继续选择其他规则集
6. 刷新目标网站，确认导入规则生效

扩展不需要账号。默认规则来源为本项目 GitHub 仓库，用户也可以选择自己信任的 HTTP 或 HTTPS 来源。
