本版支持在设置页直接获取云端社区规则，不必先下载 JSON 文件，并允许自定义规则来源。

## 主要更新

- **云端规则**：在设置页主动获取云端社区规则，在弹窗中浏览、预览并逐条选择要导入的规则。
- **自定义来源**：支持填写自己的规则来源地址，也可以一键恢复默认 GitHub 来源。
- **返回列表**：导入成功或取消预览后返回云端规则列表，方便继续选择其他规则集。
- **权限清理**：更换规则来源或删除规则时，只撤销不再使用的网站权限。

仅在用户主动点击获取时访问来源网站，不后台轮询，也不会自动启用规则；请求不携带网站 Cookie，不发送已有规则或浏览记录。Manifest 权限与 2.0.0 相同。

完整验收清单见 [发布验收](https://github.com/huaxianyan/OpenInNewTab/blob/v2.1.0/docs/release-checklist.md)。
