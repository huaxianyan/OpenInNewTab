# OpenInNewTab 2.1.0

## 新功能

- 在设置页主动获取云端社区规则，无需先下载 JSON 文件
- 在弹窗中浏览规则集，预览并逐条选择需要导入的规则
- 支持自定义规则来源地址，也可以恢复默认 GitHub 来源
- 导入或取消预览后返回云端规则列表，方便继续选择

## 修正

- 更新 PSNINE 社区规则，排除分页链接
- 清理网站权限时同时考虑当前规则来源，保留仍在使用的权限

## 权限和隐私

- Manifest 权限声明与 2.0.0 相同，安装时无需授予全部网站访问权限
- 主动获取云端规则时，请求规则来源网站的访问权限
- 仅在用户主动获取时访问来源，不进行后台轮询或自动启用
- 请求不携带网站 Cookie，不发送已有规则或浏览记录
- 来源服务提供者会接收到 IP 地址和请求时间等普通连接信息
- 云端内容仅为结构化 JSON 规则，不加载或执行远程代码
